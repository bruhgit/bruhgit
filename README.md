## 🔨 What I'm Building

- 👑 **[Uranium](https://github.com/bruhgit/Uranium-Programming-Language)** — A statically-typed systems language with a custom bytecode VM, handcrafted x86_64 JIT (no LLVM), tiered generational GC with write barriers, and VS Code LSP.
- 🦀 **[JPEF](https://github.com/bruhgit/JPEF)** — Native binary packager (`.exe`, `.elf`, `.app`) for Java Archives (`.jar`) with a high-performance Rust core and universal C-ABI bindings for 8 languages (C, C++, Rust, Go, Python, C#, TS, Java).
- ⚡ **[Bolt](https://github.com/bruhgit/Bolt)** — Hardware-accelerated, lightweight graphical interface library in pure C based on SDL3.
- 🏗️ **[OMake](https://github.com/bruhgit/OMake)** — Ultra-fast native build automation system written in C.
- 🪟 **[OpenDock](https://github.com/bruhgit/OpenDock)** — macOS-style desktop dock for Windows built with C# and WinUI 3.
- 📚 **[DevNotes](https://github.com/bruhgit/DevNotes)** — Modern developer reference notes and algorithms dictionary.
